# Provider and modality coverage

The machine-readable inventory retains C01-C26 with subtype decisions. Each row separates provider, version, subtype, modality, integration mode, implementation mode, evidence state, availability, model revision, evidence and blockers.

No provider-specific native solver is claimed in this initial release. Google, Cloudflare, hCaptcha, Arkose and the P1/P2 catalog are blocked for native recognition/owned end-to-end acceptance until licensed observations, usable model assets and documented authorized lifecycle fixtures are available.

Google v3 is risk assessment, not tile OCR. Turnstile test-key integration is not real challenge accuracy. Cloudflare interstitial refusal is not resolved through identity changes. Friendly Captcha/ALTCHA computational protocols are not image AI. Microsoft/Outlook is an integration context, not a universal algorithm.

Available independent building blocks: restricted arithmetic, generic text-line OCR, coordinate transforms/revision checks, assessment-context validation, task lifecycle and local dashboard. These building blocks do not automatically promote any provider row.

Official references: [Google verification](https://developers.google.com/recaptcha/docs/verify), [Turnstile testing](https://developers.cloudflare.com/turnstile/troubleshooting/testing/), [Turnstile Siteverify](https://developers.cloudflare.com/turnstile/get-started/server-side-validation/). Legacy Google docs are deprecated; current owner integrations require revalidation against Google Cloud Fraud Defense.
