# Numera Perception and Verification

A local recognition and owner-controlled human-verification integration laboratory.

## Language

**Capability**: One declared provider/version/modality/subtype with independent availability and evidence.
_Avoid_: Supported provider, universal solver.

**Observation**: Validated challenge data bound to an exact image/frame revision and coordinate space.
_Avoid_: Current image when its identity is not recorded.

**Recognition**: A perception result such as text, points or labels; not proof of acceptance.
_Avoid_: Solved, verified.

**Challenge completion**: An observed local widget/fixture transition, not owner-side acceptance.
_Avoid_: Server verification.

**Server verification**: Owner-side acceptance bound to the expected origin, action and session.
_Avoid_: Nonempty token, green checkbox.

**Fixture evidence**: Execution on owned or properly licensed test data, limited to its actual scope.
_Avoid_: Production reliability, universal coverage.

**Blocked capability**: A requested subtype with a concrete unmet model, data, license, hardware or authorization gate.
_Avoid_: Implemented because a name is registered.
